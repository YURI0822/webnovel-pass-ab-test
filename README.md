# 웹소설 구독 패스 무료 체험 기간 A/B 테스트

- 가상 웹소설 플랫폼 '나이트리드'의 신규 구독 상품 '정주행 패스' 무료 체험 기간(7일 vs 14일)이 유료 전환 및 매출에 미치는 영향 분석
- 모든 데이터와 설정은 분석 연습용 가상 값이며, 실제 기업·서비스와 무관

## 결과 요약

**권고: 14일 체험 전면 출시 보류, 7일 유지 + 읽기 패턴별 차등 체험 기간 후속 실험**

| 구분 | 지표 | 7일(A) | 14일(B) | 차이 | 판단 |
| --- | --- | --- | --- | --- | --- |
| 점검 | SRM / 사전 균형 | - | - | p = 1.0 / \|SMD\| < 0.01 | 통과 |
| 주요 | 체험 시작자 기준 전환율 | 29.23% | 28.81% | -0.42%p (p = 0.45) | 차이 없음 |
| 보조 | 체험 시작률 | 7.83% | 8.77% | +0.94%p (p < 0.001) | B 우세 → 선택 편향 |
| 보조 | 노출 기준 전환율 | 2.29% | 2.53% | +0.24%p (p < 0.001) | B 우세 |
| 가드레일 | 첫 달 해지율 | 26.82% | 28.34% | +1.52%p (p = 0.14) | 통과 (기준 3%p) |
| 가드레일 | 60일 총매출 (체험 시작자 1인당) | 10,896원 | 10,517원 | -378원 (95% CI 0 미포함) | B 유의 감소 |

**핵심 발견**
- 전체 평균의 작은 차이 뒤에 반대 방향 효과가 상쇄되어 있음 (세그먼트 상호작용 p < 0.001)

| 읽기 패턴 | 노출 기준 전환율 차이 | 체험 시작자 1인당 60일 총매출 |
| --- | --- | --- |
| 연재 추격형 (41%) | +0.75%p | 13,382원 → 14,228원 (+846원) |
| 완결 정주행형 (29%) | -0.47%p | 10,634원 → 8,909원 (-1,725원) |
| 탐색형 (23%) | +0.16%p (경계) | 차이 미미 |

- 연재 추격형: 긴 체험 기간 동안 최신화 확인 습관 형성 → 전환·매출 증가
- 완결 정주행형: 14일 체험 중 무료 완독 후 이탈, 패스로 코인 구매 대체 → 전환·매출 감소
- 체험 문구("14일 무료")가 체험 시작률 자체를 높여, 체험 시작자끼리의 비교에는 선택 편향 존재 → 배정 기준(노출자) 비교 병행

**후속 실험 제안**
- 연재 추격형만 14일, 나머지 7일 적용 시 예상 효과 (탐색적 추정): 노출 기준 전환율 +0.31%p, 노출자 1인당 패스 매출 +57원 (전체 7일 대비)
- 다음 설계 개선: 주요 지표를 노출자 기준 전환율로 설정, 코인 매출을 노출자 전원 기준으로 수집

**분석 흐름** ([분석 노트북](notebooks/03_ab_test_analysis.ipynb))

| 라운드 | 내용 |
| --- | --- |
| 1 | 첫인상: 기준(분모)에 따라 우세 그룹이 바뀜을 발견 |
| 2 | 실험 점검: SRM, 사전 균형(SMD) |
| 3 | 전환율 z-검정, 체험 시작률 차이로 선택 편향 확인 |
| 4 | 가드레일: 해지율, 60일 매출 (Welch t-검정 vs 부트스트랩), 패스·코인 매출 분해 |
| 5 | 읽기 패턴 세그먼트 분류, Bonferroni 보정, 상호작용 로지스틱 회귀 |
| 6 | 설계서 기준 의사결정, 차등 시나리오 추정, 한계 및 회고 |
