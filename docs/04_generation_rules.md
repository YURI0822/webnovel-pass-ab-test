# 데이터 생성 규칙 (정답지)

## 1. 개요

- 가상 데이터에 의도적으로 심어 둔 행동 규칙과 품질 이슈 정리
- 생성 코드: [notebooks/01_generate_data.ipynb](../notebooks/01_generate_data.ipynb) (난수 시드 42 고정, 실행 시 동일 데이터 생성)
- 분석 노트북은 본 문서를 보지 않은 상태에서 데이터로 도출하는 것을 전제로 작성, 분석 완료 후 결과와 대조하는 용도
- 아래 수치는 생성 직후 정제 전 기준 실측값

## 2. 생성 순서

| 단계 | 내용 | 산출 테이블 |
| --- | --- | --- |
| 1 | 설정값 정의 (규모, 비율, 가격) | - |
| 2 | 작품·유저 모집단 생성, 세그먼트 및 A/B 배정 | titles |
| 3 | 실험 전 30일 열람·결제 기록 생성 | users |
| 4 | 노출, 체험 시작, 완독, 전환, 해지 시뮬레이션 | exposures, subscription_events |
| 5 | 체험 시작 후 60일 일별 열람 및 코인 결제 생성 | daily_reading, coin_transactions |
| 6 | 품질 이슈 삽입 후 저장 | data/*.csv |

- 원인(세그먼트·배정)을 먼저 정하고 결과(행동 기록)를 나중에 생성 → 같은 유저의 기록 간 일관성 유지
- 품질 이슈는 깨끗한 데이터 생성 완료 후 마지막에 삽입 → 정제 시 원래 정답 복원 가능

## 3. 세그먼트 (숨은 변수)

- 데이터에 세그먼트 컬럼 미포함, users의 `pre30_*` 컬럼으로 분류 필요

| 세그먼트 | 비중 | 실험 전 30일 특징 |
| --- | --- | --- |
| 연재 추격형 (serial) | 45% | 연재작 열람 비중 평균 80%, 코인 결제자 약 40% |
| 완결 정주행형 (binge) | 30% | 완결작 열람 비중 평균 80%, 일 25화, 코인 결제자 약 5% |
| 탐색형 (explorer) | 25% | 무료 회차 비중 평균 70%, 열람량 적음 |

- 참고 분류 규칙: 무료 비중 50% 이상 → 탐색형 / 연재 비중 60% 이상 → 연재 추격형 / 연재 비중 40% 이하 → 완결 정주행형 / 나머지 → 혼합형
- 위 규칙 적용 시 실제 세그먼트와 약 90% 일치 (분류 오차 의도적 존재)

## 4. 심어 둔 행동 규칙

### 4.1 체험 시작률

| 구분 | A(7일) | B(14일) |
| --- | --- | --- |
| 전체 | 7.85% | 8.79% |
| 연재 추격형 | 6.90% | 7.83% |
| 완결 정주행형 | 12.02% | 13.45% |
| 탐색형 | 4.55% | 4.94% |

- B그룹 "14일 무료" 문구로 체험 시작 확률 12% 상승 → 체험 시작자 기준 비교 시 선택 편향 발생

### 4.2 체험 중 완독

- 완결 정주행형이 체험 중 주로 읽는 완결작 1편을 다 읽었는지 여부
- 완독 소요일 = 작품 회차 ÷ (일 열람량 × 완결작 비중 × 접속 확률)

| 세그먼트 | A(7일) | B(14일) |
| --- | --- | --- |
| 완결 정주행형 | 13.6% | 54.5% |
| 연재 추격형·탐색형 | 0% | 0% |

### 4.3 유료 전환율 (체험 시작자 기준)

| 세그먼트 | A(7일) | B(14일) | 차이 |
| --- | --- | --- | --- |
| 연재 추격형 | 29.7% | 36.3% | +6.6%p |
| 완결 정주행형 | 33.5% | 26.1% | -7.4%p |
| 탐색형 | 14.5% | 16.3% | +1.8%p |
| **전체** | **29.2%** | **28.8%** | **-0.4%p** |

- 전환 확률 결정 요인
  - 세그먼트 × 그룹별 기본 전환율
  - 개인 몰입도(열람량)가 높을수록 상승
  - 체험 중 완독 시 기본 확률의 55%로 하락
- 노출자 기준 전환율: A 2.29%, B 2.53% → 체험 시작자 기준과 결론 반대

### 4.4 첫 달 해지율 (유료 전환자 기준)

| 세그먼트 | A(7일) | B(14일) |
| --- | --- | --- |
| 연재 추격형 | 20.3% | 18.6% |
| 완결 정주행형 | 30.7% | 38.1% |
| 탐색형 | 35.5% | 39.3% |
| 전체 | 26.9% | 28.3% |

- 체험 중 완독한 전환자는 해지 확률 10%p 추가
- 첫 달 유지자 중 15%는 둘째 달 해지

### 4.5 잠식효과 (패스 이용 중 코인 결제 변화)

- 연재작 대기 건너뛰기 코인 결제 확률: 패스 이용 중 5%, 미이용 시 15%
- 완결작 회차: 패스 이용 중 전량 패스 열람 (코인 0), 미이용 시 40% 무료·60% 코인
- 연재작 최신화 코인 결제(25%)는 패스 유무와 무관 (최신 10화 패스 제외)
- 완결 정주행형은 패스 미이용 시 열람량 40%로 감소, 완독 후 열람량 50%로 감소

### 4.6 60일 매출 (체험 시작자 1인당)

| 구분 | A 코인 | A 총매출 | B 코인 | B 총매출 |
| --- | --- | --- | --- | --- |
| 전체 | 5,880원 | 10,887원 | 5,619원 | 10,514원 |
| 연재 추격형 | 8,181원 | 13,463원 | 7,887원 | 14,408원 |
| 완결 정주행형 | 5,044원 | 10,651원 | 4,748원 | 8,926원 |
| 탐색형 | 2,232원 | 4,588원 | 2,010원 | 4,610원 |

- 총매출 = 패스 결제액 + 코인 결제액 (코인 1개 = 100원)

## 5. 기대되는 분석 결론

- 전체 전환율 차이 미미 (-0.4%p, 유의하지 않음)
- 노출자 기준으로는 B 우세 → 체험 시작률 차이에 따른 선택 편향 확인 필요
- 60일 총매출 B 약 370원 낮음
- 세그먼트별 효과 반대 방향: 연재 추격형은 B 유리, 완결 정주행형은 A 유리
- 의사결정: 실험 설계서 8장 기준 "전환율 차이 없음 + 세그먼트별 효과 반대 방향" → 읽기 패턴별 차등 체험 기간 후속 실험 제안
