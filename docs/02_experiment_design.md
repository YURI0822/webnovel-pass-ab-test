# 정주행 패스 무료 체험 기간 실험 설계

## 1. 요약

- 7일 체험(A) vs 14일 체험(B), 21일간 50:50 배정
- 유저별 체험 시작 후 60일 관찰, 전환율과 총매출 동시 비교
- 도메인 설정: [01_domain_setting.md](01_domain_setting.md)

## 2. 설계 배경

### 2.1 실험 대상: 무료 체험 기간

- 회차 구매 중심 플랫폼에 월정액 패스 신규 도입 상황
- 신규 구독 상품 출시 시 최우선 결정 사항이 무료 체험 기간 → 실험 대상으로 선정

### 2.2 비교안: 7일 vs 14일

- A(7일): 구독 서비스에서 가장 일반적인 기본값, 현재 기획안
- B(14일): 기준안의 2배 기간 대안
- 도메인 수치와의 연결
  - 완결 정주행형 일 평균 25화, 완결작 평균 220화 → 완독까지 약 9일
  - 7일 체험: 완독 전 종료 → 결제 유인 잔존
  - 14일 체험: 체험 중 무료 완독 후 이탈 가능
  - 연재 추격형은 체험 기간이 길수록 최신화 확인 습관 형성
- 동일 변경이 세그먼트별로 반대 방향 효과 → 평균 비교만으로 판단 불가한 구조 검증 목적
- 3개 이상 비교안(예: 3·7·14일)은 그룹당 표본 감소로 모집 기간 증가 → 2개 안으로 한정

### 2.3 배정 비율: 50:50

- 총 표본 고정 시 균등 배정이 검정력 최대
- 14일 체험의 서비스 위험도 낮음 → 기준안 비중 확대 필요 없음

### 2.4 모집 기간: 21일

- 전환율 +2%p 검출: 그룹당 8,394명 → 14일
- 해지율 3%p 검출: 그룹당 유료 전환자 3,397명 → 19일
- 두 조건 충족 + 요일 효과 균등 반영 위해 3주(21일)로 설정
- 산출 근거: 6장 표본 크기 및 기간

### 2.5 보조 장치

- 노출 시점 배정: 체험 기간 문구가 체험 시작률에 영향 → 선택 편향 방지
- 60일 관찰 창: 그룹 간 첫 결제 시점 차이(D7 vs D14) 보정

## 3. 가설

- H0: 체험 기간은 체험 시작자의 유료 전환율에 영향 없음
- H1: 14일 체험이 7일 체험보다 유료 전환율 높음 (양측 검정)
- 세그먼트 가설
  - 연재 추격형: 14일 체험 시 최신화 확인 습관 형성으로 전환율 상승
  - 완결 정주행형: 14일 체험 시 체험 중 완독으로 전환율 하락
  - 탐색형: 그룹 간 차이 미미

## 4. 실험 구성

| 항목 | 내용 |
| --- | --- |
| 실험군 | A: 7일 무료 체험 / B: 14일 무료 체험 |
| 배정 단위 | 유저 (user_id 해시 기반 고정 배정) |
| 배정 시점 | 패스 소개 화면 첫 노출 |
| 배정 비율 | 50 : 50 |
| 대상 | 패스 체험 이력 없는 전체 유저 |
| 모집 기간 | 21일 (요일 효과 균등 반영) |
| 관찰 기간 | 유저별 체험 시작일로부터 60일 |

- 배정 시점을 소개 화면 노출로 설정한 이유
  - 소개 화면에 "7일 무료" / "14일 무료" 문구 노출 → 체험 기간이 체험 시작률 자체에 영향 가능
  - 체험 시작자끼리만 비교 시 선택 편향 발생 가능 → 노출 시점 배정으로 체험 시작률 차이까지 측정

## 5. 지표 체계

| 구분 | 지표 | 정의 |
| --- | --- | --- |
| 주요 | 유료 전환율 | 체험 시작자 중 체험 종료 후 첫 결제 비율 |
| 보조 | 체험 시작률 | 소개 화면 노출자 중 체험 시작 비율 |
| 보조 | 노출자 기준 전환율 | 소개 화면 노출자 중 유료 전환 비율 |
| 보조 | 체험 중 열람 회차 | 체험 기간 중 유료 회차 열람 수 |
| 보조 | 체험 중 완독 여부 | 체험 기간 내 1개 이상 작품 완독 여부 |
| 가드레일 | 첫 달 해지율 | 유료 전환자 중 2회차 결제 전 해지 비율 |
| 가드레일 | 60일 총매출 | 체험 시작자 1인당 60일간 패스 + 코인 결제액 |
| 가드레일 | 60일 코인 매출 | 체험 시작자 1인당 60일간 코인 결제액 (잠식효과 확인) |

- 매출 집계 기준을 체험 시작 후 60일로 고정한 이유
  - 첫 결제 시점이 7일 그룹은 D7, 14일 그룹은 D14로 상이
  - 동일 달력 기간 집계 시 7일 그룹에 결제 1회분 유리
  - 60일 창 적용 시 두 그룹 모두 최대 2회 결제 포함 (A: D7·D37, B: D14·D44)

## 6. 표본 크기 및 기간

- 조건: 기준 전환율 30%, 유의수준 5%(양측), 검정력 80%, 그룹당 일 600명 유입

| MDE | 그룹당 필요 체험 시작자 | 필요 모집 일수 |
| --- | --- | --- |
| +2%p (30% → 32%) | 8,394명 | 14일 |
| +3%p (30% → 33%) | 3,763명 | 7일 |
| +4%p (30% → 34%) | 2,134명 | 4일 |

- MDE: +2%p 채택 (패스 매출 규모 고려 시 사업적으로 유의미한 최소 차이)
- 해지율(기준 25%) 3%p 차이 검출: 그룹당 유료 전환자 3,397명 필요 → 19일 소요
- 모집 기간: 두 조건 모두 충족하는 21일 (그룹당 체험 시작자 약 12,600명)
- 전체 일정: 모집 21일 + 관찰 60일 = 약 81일 (전환율은 모집 종료 후 14일 시점에 선확인 가능)

## 7. 분석 계획

1. SRM 체크: 노출자 수 50:50 이탈 여부 카이제곱 검정, p < 0.001 시 분석 중단
2. 사전 균형 확인: 읽기 패턴, 결제 이력, 가입 시점, 유입 경로 비율 그룹 간 비교
3. 주요 지표 검정: 두 비율 z-검정 + 차이의 95% 신뢰구간
4. 선택 편향 확인: 체험 시작률 차이 존재 시 노출자 기준 전환율로 결론 일치 여부 확인
5. 가드레일 검정: 해지율은 비율 검정, 60일 매출은 부트스트랩 신뢰구간 (분포 비대칭)
6. 세그먼트 분석: 읽기 패턴별 효과 분리, 상호작용항 포함 로지스틱 회귀로 세그먼트 간 차이 검정
7. 다중 비교 보정: 세그먼트 분석은 탐색적 결과로 해석, Bonferroni 보정 값 병기

## 8. 의사결정 기준

| 결과 | 결정 |
| --- | --- |
| 전환율 유의 상승 + 60일 총매출 감소 없음 | B(14일) 출시 |
| 전환율 상승 + 60일 총매출 유의 감소 | A(7일) 유지, 원인 세그먼트 분석 |
| 전환율 차이 없음 + 세그먼트별 효과 반대 방향 | 읽기 패턴별 차등 체험 기간 후속 실험 |
| 전환율 차이 없음 + 세그먼트 차이 없음 | A(7일) 유지 (운영 비용 낮음) |
| 해지율 3%p 이상 악화 | 전환율 무관 B 출시 보류 |
