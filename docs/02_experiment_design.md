# 정주행 패스 무료 체험 기간 실험 설계

7일 체험(A)과 14일 체험(B)을 3주 동안 50:50으로 배정하고, 각 유저를 체험 시작 후 60일까지 관찰해서 전환율과 총매출을 함께 비교해요. 도메인 설정은 [01_domain_setting.md](01_domain_setting.md)를 따라요.

## 1. 가설

- **귀무가설(H0)**: 체험 기간은 체험 시작자의 유료 전환율에 영향을 주지 않는다.
- **대립가설(H1)**: 14일 체험은 7일 체험보다 유료 전환율을 높인다. (양측 검정)
- **세그먼트 가설**
  - 연재 추격형: 14일 체험에서 매일 최신화를 확인하는 습관이 생겨 전환율이 오른다.
  - 완결 정주행형: 14일이면 체험 중에 작품을 다 읽어서 전환율이 오히려 떨어진다.
  - 탐색형: 체험 기간과 관계없이 차이가 거의 없다.

## 2. 실험 구성

| 항목 | 내용 |
| --- | --- |
| 실험군 | A: 7일 무료 체험 (현재 기획안) / B: 14일 무료 체험 |
| 배정 단위 | 유저 (user_id 해시 기반, 한 번 배정되면 고정) |
| 배정 시점 | 패스 소개 화면 첫 노출 시점 |
| 배정 비율 | 50 : 50 |
| 대상 | 패스 체험 이력이 없는 전체 유저 |
| 모집 기간 | 21일 (요일 효과를 고르게 담기 위해 3주) |
| 관찰 기간 | 유저별 체험 시작일로부터 60일 |

**배정 시점을 '체험 시작'이 아니라 '소개 화면 노출'로 둔 이유**
소개 화면에 "7일 무료" 또는 "14일 무료"가 표시되므로, 체험 기간 자체가 체험 시작률에 영향을 줄 수 있어요. 노출 시점에 배정해야 체험 시작률 차이도 함께 측정하고, 체험 시작자끼리 비교할 때 생기는 선택 편향을 확인할 수 있어요.

## 3. 지표 체계

| 구분 | 지표 | 정의 |
| --- | --- | --- |
| 주요 지표 | 유료 전환율 | 체험 시작자 중 체험 종료 후 첫 결제가 된 비율 |
| 보조 지표 | 체험 시작률 | 소개 화면 노출자 중 체험을 시작한 비율 |
| 보조 지표 | 노출자 기준 전환율 | 소개 화면 노출자 중 유료 전환한 비율 |
| 보조 지표 | 체험 중 열람 회차 수 | 체험 기간 동안 열람한 유료 회차 수 |
| 보조 지표 | 체험 중 완독 여부 | 체험 기간 안에 한 작품 이상을 끝까지 읽었는지 |
| 가드레일 | 첫 달 해지율 | 유료 전환자 중 2회차 결제 전에 해지한 비율 |
| 가드레일 | 60일 총매출 | 체험 시작자 1인당 60일간 패스 결제액 + 코인 결제액 |
| 가드레일 | 60일 코인 매출 | 체험 시작자 1인당 60일간 코인 결제액 (잠식효과 확인) |

**매출을 '체험 시작 후 60일'로 고정한 이유**
7일 그룹은 7일차에, 14일 그룹은 14일차에 첫 결제가 나요. 같은 달력 기간으로 자르면 7일 그룹이 결제 1회분을 더 가져가서 불공정해요. 60일 창이면 두 그룹 모두 패스 결제가 최대 2회씩 들어가요(7일 그룹 7·37일차, 14일 그룹 14·44일차).

## 4. 표본 크기와 기간

**기준 조건**: 기준 전환율 30%, 유의수준 5%(양측), 검정력 80%

| 최소 검출 효과(MDE) | 그룹당 필요 체험 시작자 | 필요 모집 일수 |
| --- | --- | --- |
| +2%p (30% → 32%) | 8,394명 | 14일 |
| +3%p (30% → 33%) | 3,763명 | 7일 |
| +4%p (30% → 34%) | 2,134명 | 4일 |

- 하루 체험 시작자 1,200명이 그룹별로 600명씩 들어온다고 가정했어요.
- **MDE는 +2%p로 정해요.** 패스 매출 규모를 고려하면 2%p 차이도 사업적으로 의미가 있어요.
- 첫 달 해지율(기준 25%)에서 3%p 차이를 잡으려면 그룹당 유료 전환자 3,397명이 필요해서 19일이 걸려요.
- 그래서 모집 기간은 두 조건을 모두 충족하는 **21일**로 잡아요. 그룹당 체험 시작자는 약 12,600명이에요.
- 전체 일정은 모집 21일에 마지막 유저 관찰 60일을 더해 **약 81일 뒤** 최종 결과가 나와요. 전환율은 모집 종료 후 14일이면 먼저 확인할 수 있어요.

## 5. 분석 계획

1. **SRM 체크**: 소개 화면 노출자 수가 50:50에서 벗어나는지 카이제곱 검정으로 확인해요. p < 0.001이면 배정에 문제가 있다고 보고 분석을 멈춰요.
2. **사전 균형 확인**: 읽기 패턴, 결제 이력, 가입 시점, 유입 경로 비율이 두 그룹에서 비슷한지 확인해요.
3. **주요 지표 검정**: 전환율 차이를 두 비율 z-검정으로 보고, 차이의 95% 신뢰구간을 함께 제시해요.
4. **선택 편향 확인**: 체험 시작률이 그룹 간에 다르면, 노출자 기준 전환율로도 결론이 같은지 확인해요.
5. **가드레일 검정**: 해지율은 비율 검정, 60일 매출은 분포가 치우쳐 있어서 부트스트랩 신뢰구간을 써요.
6. **세그먼트 분석**: 읽기 패턴별로 효과를 나눠 보고, 상호작용 항이 있는 로지스틱 회귀로 세그먼트 간 효과 차이가 유의한지 확인해요.
7. **다중 비교 보정**: 여러 세그먼트를 보므로 세그먼트 분석은 탐색 결과로 해석하고, Bonferroni 보정 값도 함께 적어요.

## 6. 의사결정 기준

결과를 보기 전에 판단 기준을 먼저 정해 둬요.

| 결과 | 결정 |
| --- | --- |
| 전환율 유의하게 상승 + 60일 총매출 감소 없음 | B(14일) 출시 |
| 전환율 상승 + 60일 총매출 유의하게 감소 | A(7일) 유지, 원인 세그먼트 분석 |
| 전환율 차이 없음 + 세그먼트별 효과가 반대 방향 | 읽기 패턴별로 체험 기간을 다르게 주는 후속 실험 제안 |
| 전환율 차이 없음 + 세그먼트 차이도 없음 | 운영 비용이 낮은 A(7일) 유지 |
| 해지율이 3%p 이상 악화 | 전환율과 관계없이 B 출시 보류 |
